# Explainability Layer

This deliverable contains the **explainability layer**, which provides human-readable context for every alert generated by ARGUS. The RAG-based explanation module (`generate_note.py` and `attribution.py`) automatically maps model signals, graph heuristics, and hard rule triggers to the MITRE ATT&CK framework (`mitre_lookup.py`). This transparent reporting produces analyst-ready summaries detailing exactly why a session was flagged and which behavioral features contributed most to the risk score, allowing SOC analysts to take confident action.
