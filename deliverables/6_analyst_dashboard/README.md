# Analyst Dashboard

**Live Deployment:** [https://arguskavachh.streamlit.app/](https://arguskavachh.streamlit.app/)

## Overview

This deliverable provides the interactive Streamlit-based Security Operations Center (SOC) dashboard. It serves as the primary interface for security analysts to triage, investigate, and understand the alerts generated by the ARGUS detection engine. The dashboard visualizes the output of the fusion engine, highlighting critical alerts and providing structural and behavioral context for rapid decision-making.

## Requirement Mapping

This dashboard fulfills the requirements for Deliverable 6 as defined in the project brief:

- **"Ranked alert queue"** -> The Alert Queue tab, sorted by `fused_risk_score` in descending order.
- **"Risk score"** -> The per-alert score (0-100) and explicit Tier badge shown on every row.
- **"Contributing factors"** -> The Entity Drill-Down explanation panel, which surfaces hard rule details, MITRE ATT&CK techniques, and natural-language analyst notes.
- **"Entity history view"** -> The combined entity subgraph visualization and chronological session timeline found within the drill-down panel.

## Architecture Note

The deployed dashboard reads pre-computed scores and metrics (such as `fused_scores.parquet` and `fusion_results.json`) rather than performing live ML inference on the fly. This architecture ensures high reliability, instant load times, and memory safety when hosted on the lightweight Streamlit Community Cloud infrastructure.
